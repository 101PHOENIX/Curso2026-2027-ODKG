Data Analysis - Group 14

Primary Dataset: Fuentes de agua para beber (300051)

Domain: Smart City (Madrid Hydration Map)

1. Data and Schema Analysis

1.1 File Format and Overview

  • File: 300051-26-fuentes.csv
  • Quantities: 2,308 rows (drinking water fountains).
  • Coordinates Range: Latitude ranges from 40.333127 to 40.591954. Longitude ranges from -3.831162 to -3.546849.
  • Key Statuses: According to the dataset structure, the expected values are OPERATIVO (in service), NO OPERATIVO (out of service), and CERRADA TEMPORALMENTE (temporarily closed).

3. Resource Naming Strategy

We have defined a resource naming strategy that clearly separates the conceptual ontology from the data instances, avoiding default generic URIs.

  • Base Domain: http://smartcity.linkeddata.es/madrid/fountains/
  • Ontology URI (Classes and Properties): http://smartcity.linkeddata.es/madrid/fountains/ontology/WaterFountains#
    • Class Example: http://smartcity.linkeddata.es/madrid/fountains/ontology/WaterFountains#Fountain
    • Property Example: http://smartcity.linkeddata.es/madrid/fountains/ontology/WaterFountains#hasStatus
  • Instance URIs (Data / Resources): http://smartcity.linkeddata.es/madrid/fountains/resource/<ClassName>/<identifier>
    • Fountain Example: http://smartcity.linkeddata.es/madrid/fountains/resource/Fountain/10234
    • District Example: http://smartcity.linkeddata.es/madrid/fountains/resource/District/Retiro
