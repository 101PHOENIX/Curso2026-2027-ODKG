Complementary Datasets: Contaminación acústica. Estaciones de medida (211346) & Censo de locales, sus actividades y terrazas de hostelería y restauración (200085) (terraces file only)

Analysis date: 5 October 2026. Figures were computed on the full CSV file downloaded from the portal on that date. The file in csv/contaminacion_acustica.csv is an extract of the original file with all rows from 2020 on (01/01/2020 – 04/10/2026): 295,853 rows, 31 stations, about 13 MB, same encoding and format as the original.

1. Data and Schema Analysis

1.1 File Format and Encoding
  • File: 215885-0-contaminacion-ruido.csv, about 44.7 MB.
  • Encoding: ISO-8859-1 (Latin-1), not UTF-8. The header Estación;Año;Mes;Día is broken if read as UTF-8.
  • Separator: semicolon (;). Line endings: CRLF.
  • Decimal mark: comma (68,9). Values have at most one decimal; whole values have none (68).
  • Missing values: the string N/D (no disponible).
  • Update: daily, except weekends and public holidays. The last day in the file is 04/10/2026.
1.2 Schema of the Daily Measurements (215885)

Each row is the value of one station, for one day and one period. The key of a row is (Estación, Año, Mes, Día, Periodo); no duplicate keys were found.

Data Quality Issues Found

  • Different station codes: the measurements use integers (2), the catalog uses RF-02. Mapping: n → RF- + n padded to two digits.
  • Stations without catalog entry: codes 7, 9, 21, 22 and 23 (2009–2010) are not in the catalog, so they have no name or coordinates.
  • Outliers: 4 rows above 100 dB(A) (stations 18 and 13, April and August 2007, up to 140.2) and 39 rows below 35 dB(A). They are physically doubtful; we keep them but will flag them.
  • Percentile issues: 4 rows contain 0 in a percentile, and in 4,262 rows (0.6%) the order L1 ≥ L10 ≥ L50 ≥ L90 ≥ L99 is not respected.
  • Catalog formatting: broken coordinates (-3.691.877); a trailing space in "Carabanchel "; neighbourhood Quitana should be Quintana; RF-01 has FECHA ALTA 07/03/2011 although station 1 has data since 1998.

2. Licensing of the Data Source

2.1 Publisher

The dataset is published on the open data portal of the city, datos.madrid.es. In the DCAT metadata of the dataset, dct:publisher and dct:creator are both http://datos.gob.es/recurso/sector-publico/org/Organismo/L01280796, which is the DIR3 code of the Ayuntamiento de Madrid.

The unit responsible for the data (Responsable del conjunto de datos) is the Dirección General de Sostenibilidad y Control Ambiental (Departamento de Control Acústico, Área de Urbanismo, Medio Ambiente y Movilidad). The data comes from its SIVCA network (Sistema Integral de Vigilancia de la Contaminación Acústica).

2.2 Rightsholder

The rightsholder is the Ayuntamiento de Madrid. The portal's terms of use apply to the reuse of "documents held by the Ayuntamiento de Madrid", and the station catalog (211346) and terraces census (200085) belong to the same body.

We will publish the generated RDF dataset and our ontology under CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/).

  • The generated data is an adaptation of CC BY 4.0 data, so the attribution to the Ayuntamiento de Madrid must stay with it. Using the same licence keeps this clear and creates no conflict.
  • A public-domain licence (CC0) is not a good choice: users of our data would no longer be told that they must credit the original source.
  • A more restrictive licence (for example NC or ND) would limit the reuse of open data, and would go against the spirit of the source.
