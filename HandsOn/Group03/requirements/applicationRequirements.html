Application requirements

Terraces and night-time noise in Madrid – Hands-on 1 · Group XX

1. Purpose of the application

The application lets a user explore the following question:

Is there an association between the number of registered terraces near a noise monitoring station and the night-time noise levels measured by that station?

It combines the noise measurements of the Madrid noise monitoring network with the location of registered terraces, and shows both on a map and in a chart so that the user can check whether stations surrounded by more terraces tend to record higher night-time noise.

2. Datasets the application is built on

DatasetRole in the applicationSource and license
Contaminación acústica. Datos diarios (selected dataset)Daily noise levels per station. The night-time indicator Ln (equivalent sound level, 23:00–07:00, in dB(A)) is the noise value used by the application.datos.madrid.es/dataset/215885-0-contaminacion-ruido · CC BY 4.0 · updated daily · 50 measuring stations
Contaminación acústica. Estaciones de medidaIdentifier, name and coordinates of each station. Needed to place stations on the map and to count terraces around them.datos.madrid.es (same portal and publisher, linked from the noise dataset page)
Registered terraces (hospitality terraces)Location of each terrace. Source of the terrace count per station.datos.madrid.es (to be confirmed by the group: exact dataset, CSV format and license)

The idea requires combining the noise data with a second source (terraces), so the application also covers optional requirement R6 (multiple data sources). Stations and terraces are linked through their geographic location.

3. Users

  • Citizen: wants to know whether living near an area with many terraces is related to higher night-time noise.
  • Analyst at the city council or a researcher: wants to check the relationship with different distances and dates.

4. Functional requirements

IDRequirement
FR1The application shall show a map with all noise monitoring stations.
FR2The user shall be able to choose a radius (for example 100, 250 or 500 m) around the stations.
FR3For each station, the application shall compute and show the number of terraces within the chosen radius.
FR4The user shall be able to choose a date range. For each station, the application shall compute and show the average night-time noise level (Ln) in that range.
FR5The application shall show a scatter plot with one point per station: terraces within the radius (x axis) against average night-time noise (y axis).
FR6The application shall show the correlation coefficient of the scatter plot, together with the number of stations used.
FR7When the user selects a station (on the map or in the chart), the application shall show its name, its terrace count and its average night-time noise level.
FR8Stations without noise data in the selected date range shall be left out of the chart and the coefficient, and the application shall tell the user how many were left out.

5. Questions the data must answer

  1. How many terraces are within R metres of each station?
  2. What is the average night-time noise level (Ln) of each station between dates D1 and D2?
  3. Which stations have the highest number of terraces and what are their night-time levels?
  4. What is the correlation between questions 1 and 2 over all stations?

6. Non-functional requirements

IDRequirement
NFR1The application shall use only open data published under an open license, and shall show the attribution required by CC BY 4.0.
NFR2The application shall obtain its data from the RDF data published by the group (linked to the generic entities used for locations), not from the original CSV files.
NFR3The application shall update the map and the chart in less than 3 seconds after the user changes the radius or the date range.
NFR4The application shall run in a standard web browser, on desktop screens and on mobile screens.
The application shows an association, not a cause. A result such as “more terraces, higher night noise” does not prove that terraces cause the noise (traffic, nightlife areas or other sources can influence both). The interface will state this next to the coefficient.
