Parking Occupancy Application

Application Description

This application will use parking occupancy data to allow users to explore information about public parking facilities.

Main Objective

The main objective is to create a simple web application where users can search, filter and visualize parking occupancy information.

Functional Requirements

ID Requirement
R1 The application must display parking information.
R2 The user must be able to filter parking facilities by district.
R3 The user must be able to filter parking facilities by parking type.
R4 The user must be able to select a year and month.
R5 The application must show the parking occupancy percentage.
R6 The application must show the number of parking spaces.
R7 The application must support RDF data.
R8 The application must allow RDF data to be queried using SPARQL.
R9 The application must represent parking facilities, districts and occupancy records as RDF resources.
R10 The application must display the results of RDF/SPARQL queries in a simple table.

Non-Functional Requirements

  • The application should be simple and easy to use.
  • The application should work in modern web browsers.
  • The interface should work on desktop and mobile screens.
  • The RDF model should use clear URIs.
  • The application should return SPARQL query results in a readable format.

Expected Result

The final application should allow a user to explore the parking dataset using simple filters and also access the same information through an RDF model and SPARQL queries.
