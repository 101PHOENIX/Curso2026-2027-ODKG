Application Requirements, Active Madrid

Hands-on 1, Open Data and Knowledge Graphs, An application built on a knowledge graph of sports facilities and classes in Madrid

1. Application overview

Active Madrid is a web application that helps people find available spots for sports activities in Madrid. It is built on a knowledge graph that links:

  • the basic municipal sports facilities (D1);
  • the open classes with available spots (D2);
  • the closed classes or full activities (D3);
  • external entities from Wikidata: districts, sports, and metro stations.

Each class is linked to a facility, so the app can show exactly where activities take place. Users can search for a class by sport or district, see how many spots are available, and compare districts by sports supply.

2. Target users

UserNeed
Amateur athleteFind a nearby facility with an open class for their favorite sport.

City plannerCompare districts by number of sports facilities and availability of classes.

3. Functional requirements

IDRequirementDataset used
FR1Display the sports facilities on a map.D1
FR2Filter facilities by sport, district, and availability of spots using a top search bar.D1, D2, D3
FR3Show a split view with a result list on one side and a dynamic map on the other.D1, D2
FR4Show a facility detail page: address, district, equipment, and public transport.D1
FR5On the facility page, list all open classes and closed classes with their schedules and number of available spots.D1, D2, D3
FR6Recommend the facilities with the highest number of available spots for a given sport in a district.D1, D2
FR7Rank districts by number of sports facilities and total available spots.D1, D2
FR8Show linked information from Wikidata for districts, sports, and metro stations.Wikidata
FR9Show the source and license of the data (CC BY 4.0, Madrid City Council).Metadata

4. Non-functional requirements

IDRequirement
NFR1All data is queried through SPARQL over the knowledge graph generated from the CSV files.
NFR2The application runs in a web browser and is responsive on mobile devices.
NFR3Each query issued by the interface returns in under 3 seconds.
NFR4Standard vocabularies are reused where possible: GeoSPARQL/WGS84 for locations, and schema.org for a facility and a class.
NFR5The attribution required by the CC BY 4.0 license is displayed.
NFR6The interface is available in English and Spanish and uses accessible colors.

5. Competency questions

  1. Which facilities in the district of Retiro have open classes for tennis?
  2. How many available spots are there for swimming classes at a given facility?
  3. Which district has the most sports facilities?
  4. Which facilities are near a given metro station?
  5. What is the Wikidata entity for the sport of judo?
