3. D1, Sports Centers Information

R1. Smart city domain ✔

The dataset belongs to the urban public services domain. It contains the inventory of municipal sports facilities in Madrid, providing essential infrastructure data for citizens.

R2. Available as CSV ✔

The dataset is available as a standard CSV file.

R3. Open license ✔

Creative Commons Attribution 4.0 International (CC BY 4.0), allowing the data to be copied, transformed, and redistributed.

R4. Linkable to real-world entities ✔

This dataset contains geospatial coordinates, addresses, and district identifiers, allowing it to be linked directly to Wikidata entities representing Madrid districts and neighborhoods.

4. D2, Open Classes

R1. Smart city domain ✔

The dataset describes the public activities available to citizens, directly contributing to public health and urban life management.

R2. Available as CSV ✔

The dataset is available as a standard CSV file.

R3. Open license ✔

CC BY 4.0, with the same conditions as D1.

R4. Linkable to real-world entities ✔

This dataset contains the types of sports, which can be linked to Wikidata entities representing sports (e.g., swimming, tennis). It links geographically through its relationship with D1.

5. D3, Closed Classes

R1. Smart city domain ✔

Similar to D2, this dataset provides information about the saturation and usage of public services.

R2. Available as CSV ✔

The dataset is available as a standard CSV file.

R3. Open license ✔

CC BY 4.0, with the same conditions as D1.

R4. Linkable to real-world entities ✔

This dataset links to specific sports on Wikidata and connects to physical locations via D1.

6. How the datasets are linked

D1 ↔ D2: Each open class in D2 references a specific facility in D1 using a facility identifier.

D1 ↔ D3: Each closed class in D3 references a specific facility in D1 using a facility identifier.

All ↔ Wikidata: The datasets link to Wikidata for districts, sports, and transit stations.

7. Conclusion

All three datasets satisfy the mandatory requirements R1 to R4. The integration of a facility dataset with class availability datasets provides a robust knowledge graph for the assignment.
