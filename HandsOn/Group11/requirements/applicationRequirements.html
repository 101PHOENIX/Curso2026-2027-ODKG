SafeRoute Madrid - Application Requirements

Application requirements for the smart navigation system designed to warn drivers about accident-prone locations across the city of Madrid, utilizing open-source routing data and predictive accident analysis models.

Functional Requirements:

  1. Allow users to input their starting point and destination point within or around Madrid.
  2. Enable users to specify their type of vehicle (e.g., car, motorcycle, truck, bicycle) for tailored risk assessments.
  3. Integrate with a routing API (such as OpenRouteService) to calculate optimal paths.
  4. Apply predictive analytics algorithms on historical Madrid accident data to identify high-risk zones along or near the route.
  5. Generate real-time safety warnings and risk scores when routes pass through accident-prone areas, emphasizing vehicle-specific hazards.
  6. Offer alternative route suggestions or deviation options to bypass dangerous blackspots.
