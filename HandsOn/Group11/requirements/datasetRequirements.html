Dataset Requirements

R1. Data are in the smart cities domain.

This requirement is satisfied. We have chosen datasets containing traffic accident data for the city of Madrid. Traffic accidents and road safety are part of the smart cities domain because the data can be used to analyse mobility and improve transportation and road safety within the city.

R2. Data are available as CSV files.

This requirement is satisfied. The selected datasets are available in CSV format. We have included traffic accident datasets from 2025 and 2026. During the project, additional years may also be included if more historical data is required for the analysis.

R3. Data have an open license so they can be published.

This requirement is satisfied. The data are published under the Creative Commons Attribution 4.0 International (CC BY 4.0) license. Therefore, the data can be reused and published as long as appropriate attribution is given to the original source.

R4. Data can be easily linked with generic real-world entities.

This requirement is satisfied. The traffic accident datasets contain information that can be linked with several real-world entities, especially geographical entities in Madrid.

For example, the accident data can be linked to Madrid districts using district information and codes. These districts can be connected with the Madrid City Council dataset containing information about the municipal districts of Madrid.

Accident locations can also be linked to streets and other road-related datasets. This would allow us to enrich the accident data with additional information about the roads, such as the number of lanes, the existence of bicycle or bus lanes, and traffic intensity.

In addition, the type of vehicle involved in an accident can be represented as another real-world entity. These links would allow the dataset to be enriched with external information and provide more context when analysing accident-prone locations.

R5. Documentation exists for the data (optional).

This optional requirement is satisfied. Documentation describing the traffic accident dataset is available as a PDF file in the requirements directory. The documentation describes the columns of the dataset, variable types, the meaning of different codes, and the overall structure and meaning of the data.

R6. Data can come from multiple data sources (optional).

This optional requirement is currently not satisfied. At the moment, we have selected traffic accident datasets from different years, specifically 2025 and 2026, but they come from the same data source.

However, during later stages of the project, the accident data may be enriched with other datasets, such as information about Madrid districts, streets, road characteristics, or traffic intensity. This could allow us to work with multiple data sources in the future.
