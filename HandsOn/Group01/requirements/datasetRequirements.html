Dataset Requirements

Dataset

The selected dataset is US Accidents (2016–2023), created by Sobhan Moosavi et al. For this project, we use a subset containing traffic accidents from New York City.

The original dataset is very large, so it was not practical to include the complete dataset in the repository. Therefore, a subset containing only traffic accidents from New York City was created and used for this project, while preserving the original structure and attributes.

Original source: US Accidents (2016–2023) - Kaggle

R1. Data are in the smart cities domain

The dataset satisfies this requirement because it contains information about traffic accidents and urban mobility, which are relevant topics in the Smart Cities domain.

R2. Data are available as a CSV file

The selected data are available in CSV format.

R3. Data have an open license so it can be published

This requirement is satisfied. The original US Accidents (2016–2023) dataset is distributed under the Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International (CC BY-NC-SA 4.0) license.

This license allows the dataset to be reused, shared and adapted for non-commercial purposes, provided that appropriate attribution is given and derivative works are distributed under the same license.

Original dataset: US Accidents (2016–2023) - Kaggle

R4. Data can be easily linked with generic real-world entities

The dataset contains geographic information such as latitude, longitude, street, city, county, state and postal code. These values can be linked with real-world entities such as New York City, streets, counties and geographic locations.

Entities in the dataset that can be linked

  • City: the City attribute can be linked with real-world city entities, such as New York City.
  • County: the County attribute can be linked with county entities, such as Kings County, Queens County or New York County.
  • State: the State attribute can be linked with the New York State entity.
  • Street: street names can potentially be linked with existing geographic entities representing streets and roads.
  • Geographic location: the Start_Lat and Start_Lng attributes can be used to identify and link geographic locations.
  • Postal code: the Zipcode attribute can be linked with geographic areas represented by postal codes.

Entities in other datasets that can be linked

The geographic entities contained in the selected dataset can be linked with corresponding entities available in external Linked Data sources such as Wikidata and DBpedia.

  • New York City can be linked with the corresponding New York City entity in Wikidata or DBpedia.
  • New York State can be linked with the corresponding New York State entity in Wikidata or DBpedia.
  • Counties such as New York County, Kings County, Queens County, Bronx County and Richmond County can be linked with their corresponding geographic entities in Wikidata or DBpedia.
  • Streets and other geographic locations may also be linked with corresponding entities from external geographic datasets when available.

R5. Documentation exists for the data

This requirement is satisfied. The original US Accidents (2016–2023) dataset includes detailed documentation on its Kaggle page. The documentation explains the purpose and origin of the dataset, the time period covered, the data collection process, and the meaning of the different attributes contained in the CSV file.

For example, the dataset documentation describes attributes such as ID, Source, Severity, Start_Time, End_Time, geographic coordinates, street, city, county and state. The Kaggle page also references scientific publications that provide additional information about the creation and use of the dataset.

Dataset documentation: US Accidents (2016–2023) - Metadata and Documentation

R6. Data can come from multiple data sources

This requirement is satisfied. According to the dataset documentation, the accident information was collected using multiple traffic APIs that provide streaming traffic incident data.

These APIs aggregate information captured by different types of sources, including US and state departments of transportation, law enforcement agencies, traffic cameras and traffic sensors located within road networks. Therefore, although the final dataset is distributed as a single CSV file, the information originates from multiple data sources.
